# docs/screenshots/ — 제출·사용법용 화면 캡처

## 역할

`docs/usage_guide.md`, `docs/submission_outline.md`, 제출 PDF에 넣을 화면 캡처를 둔다 (9/19~20).

> **캡처 환경 (사용자 결정 2026-09-17):** 공개 배포가 보류되어 **로컬 실행 + 합성 자료**로 찍는다. 사용자 Chrome과 분리된 창 없는 Chrome으로 찍어 주소창·북마크가 들어가지 않는다.
>
> **다시 찍기:** `uv run python scripts/capture_screenshots.py` (3단계 AI 참고 의견 포함, Ollama와 `gemma4:26b-a4b-it-qat` 필요) · `--no-ai`면 AI 영역 없이.
> 스크립트는 셸의 `PSM_` 설정을 비우고 합성 근거로 서버를 따로 띄우며, 상단 표시가 "시연용 합성 수치"가 아니면 멈춘다. AI 문장은 찍을 때마다 달라지므로 찍은 뒤 확인한다.

## 만들 파일

| 파일 이름 규칙 | 내용 |
|---|---|
| `01_input_sample.png` | 1단계: 예시 기획 입력 완료 상태 |
| `02_evidence_national.png` | 2단계: 전국 참고 근거, 차트·월별 표 |
| `02_evidence_hold.png` | 2단계: 자료 부족 보류 사례 |
| `03_questions.png` | 3단계: 검토 의견과 검토하지 않은 항목 |
| `04_choices_option_a.png` | 4단계: 참여 실적 추가 선택과 실행 조건 입력 |
| `05_draft_compare.png` | 5단계: 보완 기획안 (변경·추가 줄 표시, 변경 전후 표, 근거 추적 패널) |
| `05_saved_markdown.png` | 저장한 Markdown을 외부 편집기로 연 화면 (**사용자가 직접 캡처**. 스크립트로 만들지 않음) |

번호는 단계, 뒤는 화면 상태를 뜻한다. 같은 화면을 다시 찍으면 덮어쓴다.

## 원칙

- **합성 수치 화면만** 둔다. 상단의 "시연용 합성 수치" 표시가 보이게 찍는다
- 실제 분석 결과 화면 캡처는 공개 저장소에 올리지 않는다 (팀 비공개 공간 또는 `private/`)
- 브라우저 주소창·개인 북마크·다른 탭이 보이지 않게 찍는다
- 가로 1440px 기준, PNG. 01·02_national·03·05는 전체 페이지, 02_hold는 1440×900, 04는 1440×1300 화면 한 장
- 04의 입력 예시: 수집 자료 "쿠폰 사용 실적, 참여 점포 정산 자료", 확보 여부 "협의 중", 담당 "관광정책과", 주기 "월 1회" (사용자 확인 9/17)
