# docs/screenshots/ — 제출·사용법용 화면 캡처

## 역할

`docs/usage_guide.md`, `docs/submission_outline.md`, 제출 PDF에 넣을 화면 캡처를 둔다 (9/19~20).

## 만들 파일

| 파일 이름 규칙 | 내용 |
|---|---|
| `01_input_sample.png` | 1단계: 예시 기획 입력 완료 상태 |
| `02_evidence_national.png` | 2단계: 전국 참고 근거, 차트·월별 표 |
| `02_evidence_hold.png` | 2단계: 자료 부족 보류 사례 |
| `03_questions.png` | 3단계: 검토 의견과 검토하지 않은 항목 |
| `04_choices_option_a.png` | 4단계: 참여 실적 추가 선택과 실행 조건 입력 |
| `05_draft_compare.png` | 5단계: 원안 ↔ 보완안 비교, 근거 추적 패널 |
| `05_saved_markdown.png` | 저장한 Markdown을 외부 편집기로 연 화면 |

번호는 단계, 뒤는 화면 상태를 뜻한다. 같은 화면을 다시 찍으면 덮어쓴다.

## 원칙

- **합성 수치 화면만** 둔다. 상단의 "시연용 합성 수치" 표시가 보이게 찍는다
- 실제 분석 결과 화면 캡처는 공개 저장소에 올리지 않는다 (팀 비공개 공간 또는 `private/`)
- 브라우저 주소창·개인 북마크·다른 탭이 보이지 않게 찍는다
- 가로 1440px 기준, PNG
