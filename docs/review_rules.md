# 검토 규칙 설명 (R01~R07)

문서 기준일: 2026-09-16
원본 파일: `src/policy_signal_map/resources/rules/review_rules.json` (문구·대안) + 규칙 ID별 파이썬 함수 (조건)
기준: 워크플로우 11장·S02, 최종기획서 4-3·4-4·5장
**데이터 담당 검수 대상:** 아래 표의 "실행 조건"과 "질문 문구". 검수 칸에 날짜를 적어 주세요.

이 문서와 JSON의 규칙 ID·문구는 항상 같아야 한다. `tests/test_review_rules.py`가 두 파일의 규칙 ID 일치를 검사한다.

## 공통 원칙

- 서비스는 판정하지 않는다. 관측을 **질문**으로 전달하고 결정은 담당자가 한다 (최종기획서 1장)
- 문구에 "문제·오류·위험·실패·성공·잘못"을 쓰지 않는다 (테스트로 확인)
- 반대 방향 구간이 없다고 "검토가 필요 없다"고 하지 않고, 있다고 "비중을 삭제하라"고 하지 않는다 (워크플로우 8-3)
- 방향이 같은 기간에는 "방향이 달랐다"는 예시 문구를 쓰지 않는다 (12장)
- 전국 근거를 특정 지역 진단처럼 표시하지 않는다 (8-4)
- 결과는 다섯 가지로 구분한다

| 결과 | 뜻 |
|---|---|
| `question` | 담당자 선택이 필요한 질문 |
| `notice` | 오류로 표시하지 않고 해석 조건만 안내 |
| `pending` | 추가 확정 필요 항목 |
| `held` | 근거가 부족해 결론 보류 |
| `not_reviewed` | 이번 범위에서 검토하지 않음 ("문제없음"과 다름) |

조건을 확인했지만 물을 것이 없으면 `no_finding`(확인했으나 해당 없음)으로 따로 표시한다.

## 선택 방식 (4단계)

| 결과 | 4단계에서 |
|---|---|
| `question` | 원안 유지 / 채택 / 수정 / 보류 중 하나를 **반드시** 고른다 (보류도 결정) |
| `notice` | 대안 B(해석 조건 명시)나 원안 유지를 고를 수 있다. **고르지 않아도 다음 단계로 간다** |
| `pending`·`held` | 선택하지 않는다. 보완 기획안 8장(추가 확인사항)에 사유·근거와 함께 자동 기록된다 |
| `not_reviewed` | 문서에 반영하지 않는다 |

## R07 금액·비중과 성과지표 확인 — 검토 구현

| 항목 | 내용 |
|---|---|
| 실행 대상 | 성과지표에 "외국인 결제 비중" 또는 "외국인 결제금액"이 있을 때 |
| 근거 | 전국 레코드의 비교 A(금액 vs 전체 분모 비중) 구간 요약 |
| 실행하지 않음 | 지표가 없으면 결과 없음 |

실행 판단 순서

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | 전국 근거 레코드 없음 | `held` "전국 근거 자료가 없어 금액·비중 비교를 보류합니다." |
| 2 | 적용 상태 `blocked` | `held` "현재 자료로 금액·비중 비교를 사용할 수 없습니다. 사유: {reason}" |
| 3 | 적용 상태 `needs_review` | `held` "근거 기반 결론을 보류합니다. 확인할 내용: {reason}" |
| 4 | 비교 가능 구간 0개 | `held` "비교 가능한 인접 월 구간이 없어 방향 비교를 보류합니다." |
| 5 | 지표 용도 = 참고 현황 | `notice` (아래 문구) |
| 6 | 지표 용도 = 직접 성과평가 | `question` |
| 7 | 지표 용도 = 아직 모름 | `question` (결론 없이 선택지만) |

문구

| 상황 | 문구 |
|---|---|
| 질문 (직접 평가) | "외국인 결제 비중은 외국인 결제금액뿐 아니라 전체 결제금액의 변화에도 영향을 받습니다. 이 사업에서 확인하려는 것은 외국인 결제금액 확대인가요, 전체 결제에서 외국인 비중 확대인가요? 직접 성과평가에 쓴다면 참여자의 쿠폰 사용·정산 자료를 따로 모을 수 있는지도 알려 주세요." |
| 질문 (아직 모름) | "선택한 지표를 참고 현황으로 쓸지, 사업 성과를 직접 평가하는 기준으로 쓸지에 따라 확인할 자료가 달라집니다. 어느 쪽에 가까운지 알려 주세요." |
| 안내 (참고 현황) | "참고 현황으로 사용하는 지표입니다. 성과 판단에 쓰지 않으므로 그대로 두어도 됩니다. 문서에는 분모 기준(전체·미상 제외)과 전국 참고 범위를 적어 두는 것만 권합니다." |
| 목표 불일치 앞말 | "입력한 목표는 ‘{목표}’인데 성과지표는 ‘{지표}’입니다. 두 가지가 가리키는 방향이 다를 수 있습니다. " |
| 왜 묻나요 (반대 구간 있음) | "{기간} 전국 자료에서 비교 가능한 {comparable_count}개 인접 월 구간 중 {opposite_count}개 구간에서 외국인 결제금액과 전체 분모 비중의 변화 방향이 달랐습니다." |
| 왜 묻나요 (반대 구간 없음) | "{기간} 전국 자료에서는 두 지표가 서로 반대 방향으로 움직이지 않았습니다. 다만 금액과 비중은 서로 다른 질문에 답하므로 어떤 지표로 성과를 확인할지는 정해 두는 편이 좋습니다." |
