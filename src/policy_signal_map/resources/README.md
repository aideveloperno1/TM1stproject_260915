# resources/ — 코드가 읽는 공개 자료

## 역할

코드와 분리해 관리하는 자료 파일. 문구·규칙·양식·합성 데이터를 바꿀 때 Python 코드를 고치지 않아도 되게 한다.
이 폴더는 공개 저장소와 공개 배포에 그대로 포함된다. **실제 카드 분석 결과를 두지 않는다.**

## 하위 폴더

| 폴더 | 내용 |
|---|---|
| `rules/` | 검토 규칙 원본 |
| `evidence/` | 합성 분석 근거 파일 |
| `documents/` | 보완 기획안·요청서 Markdown 양식 |
| `prompts/` | AI 참고 의견 요청 문장 (`opinion.txt`) |
| `llm/` | AI 모델 표시 이름·설명 (`models.json`). 고를 수 있는 모델 자체는 `.env`의 `PSM_LLM_MODELS`가 정한다 |

## 만들 파일

| 파일 | 상태 | 내용 |
|---|---|---|
| `regions.json` | 있음 | 시도 17개·시군구 269개. `scripts/build_regions.py`로 생성, 손으로 고치지 않음 |

## 원칙

- 모든 파일은 UTF-8
- JSON 파일에는 `version` 필드를 두고, 구조를 바꾸면 버전을 올린다
- 읽는 코드는 시작 시 형식을 검사하고, 틀리면 조용히 넘어가지 않고 오류로 멈춘다
- `scripts/check_public_bundle.py`가 이 폴더에 실제 자료가 없는지 검사한다
