# web/static/css/ — 스타일

## 만들 파일

| 파일 | 상태 | 내용 |
|---|---|---|
| `style.css` | 있음 (단계별 확장) | 전체 화면 스타일 |

`style.css` 하나로 유지한다. 700줄을 넘으면 `base.css`(토큰·레이아웃·버튼) / `steps.css`(단계별)로 나눈다.

## `style.css` 구성 (주석 구역 순서)

1. **디자인 토큰** (`:root`) — 시안 색상: 배경 #F1F4F9, 카드 #FFFFFF, 본문 #1B2430, 강조 #2563EB, 추가 확정 필요 #A8761A / #FDF4DE, 오류 #C2410C(입력 오류에만)
2. **상단바·단계 표시줄** — 있음
3. **레이아웃** — 본문+오른쪽 패널 2열, 900px 이하 1열 — 있음
4. **카드·버튼** — 있음
5. **입력** — 칩, 세그먼트, 강조 박스, 오류 — 있음
6. **오른쪽 패널** — 요약, 규칙 목록 — 있음
7. **근거 화면** (있음) — 범위 칩, 안내·보류 상자, 요약 문장, 차트 카드·대체 문구, 표(가로 스크롤, 보류 행 회색, 방향 다름 굵게), 계산 방법·해석 한계 카드, 보류 사례 접힘 영역, 오류 목록. `.stack`은 `minmax(0, 1fr)`로 표 최소 폭이 본문을 밀어내지 않게 함 (9/16 400px 폭에서 본문 766px로 넓어지는 문제를 발견해 수정)
8. **검토 질문** (있음) — kind별 규칙 카드 (질문: 파란 테두리 / 안내: 회색 / 추가 확정 필요: 노랑 / 보류: 회색 점선), 근거 칩, "왜 묻나요?" 박스
9. **보완 선택** (있음) — 대안 카드 선택 상태, 실행 조건 입력 박스(파란 점선), 재확인 필요 목록
10. **보완 기획안** (있음) — 문장 줄(변경·추가는 파란 배경과 칩), 근거 추적 패널, 문서 보기(`pre`), 변경 전후 표
11. **인쇄·PDF 저장** (있음) — `@media print`: A4 14mm/12mm 여백, 상단바·단계 표시줄·버튼 숨김, 카드 그림자 제거와 `break-inside: avoid`, 표 최소 폭 해제(인쇄 가능 폭 186mm에서 잘리지 않음), 하단 고지는 남김. 배경색이 꺼져도 구분되게 변경 줄은 **왼쪽 선**으로 표시

## 원칙

- 방향 차이를 빨간색으로 표시하는 클래스를 만들지 않는다 (워크플로우 8-3)
- 한글 라벨에 고정폭 글꼴(monospace)을 쓰지 않는다 (글자 간격 깨짐 확인됨). 숫자 열에만 `font-variant-numeric: tabular-nums`
- 모바일 폭(400px)에서 가로 스크롤은 표·문서 영역 안에서만 생기게 한다
