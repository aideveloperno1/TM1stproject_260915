# web/templates/steps/ — 단계별 화면

## 만들 파일

| 파일 | 상태 | 단계 | 라우트 |
|---|---|---|---|
| `input.html` | 있음 | 1 기획 입력 | `routes/input.py` |
| `evidence.html` | 있음 | 2 근거 확인 | `routes/evidence.py` |
| `questions.html` | 있음 | 3 검토 질문 | `routes/questions.py` |
| `choices.html` | 있음 | 4 보완 선택 | `routes/choices.py` |
| `draft.html` | 있음 | 5 보완 기획안 | `routes/draft.py` |
| `document.html` | 있음 | 5 전체 문서 보기 | `routes/draft.py` |
| `request.html` | 있음 | 5 정밀 분석 요청서 초안 | `routes/draft.py` |

임시 화면 `placeholder.html`은 5단계 구현과 함께 삭제했다.

## 화면별 구성

### `input.html` (있음)

왼쪽 입력 카드 + 오른쪽 패널(입력 상태, 검토 예정 규칙). 필수·선택 표시, 기타 입력칸, 지역 선택, 예산 미정, 강조 박스(성과지표·지표 용도), [예시 기획 채우기]·[모두 지우기]·[검토 시작].

### `evidence.html`

시안 S2 기준.
1. 범위 칩: `partials/evidence_badges.html` (전국 참고·기간·자료 버전·합성/실제)
2. 요약 문장: "1~6월 전국 합산에서 5개 인접 월 구간 중 N개 구간에서 외국인 결제금액과 비중의 변화 방향이 달랐습니다." — N=0이면 다른 문장 (반대 문구 복사 금지)
3. 차트 2개: 외국인 결제금액(억원) 막대, 외국인 결제 비중(%) 선 + [전체 분모 | 미상 제외] 전환 (`static/js/charts.js`)
4. 월별 표: `partials/month_table.html`
5. 인접 구간 칩 5개: 방향 같음/다름/보류, 작은 차이는 "0.01%p 미만"
6. 계산 방법 카드, 해석 한계 카드
7. [자료가 부족한 경우 보기] 접힘 영역: 보류 레코드 (자료 없음은 0으로 표시하지 않음)
8. [검토 질문 보기 →]

### `questions.html`

시안 S3 기준. 왼쪽: 검토 의견 N건 (`partials/rule_card.html`), 각 카드에 근거 칩·"왜 묻나요?". 오른쪽: 검토하지 않은 항목과 이유. C 단계에 "AI 참고 의견" 영역 추가. [보완 방법 고르기 →]

### `choices.html`

시안 S4 기준. 질문별로 대안 카드(바뀌는 곳·필요 자료·운영 부담) + [원안 유지] [보류] [수정]. 옵션 A 선택 시 실행 조건 입력 박스. 재확인 필요 목록을 상단에. 안내 문구 "서비스는 정답을 고르지 않습니다. 성공 확률이나 점수를 표시하지 않습니다." [보완 기획안 만들기 →]

### `draft.html`

시안 S5 기준. 요약 "변경 N건 · 추가 확정 필요 N건 · 원안 유지 N개 장", 장별 문장 목록(변경·추가 줄은 파란 배경 + [변경]/[추가] 칩 + 근거 칩), 추가 확정 필요 목록, 변경 전후 표, 근거 추적 패널. 버튼: [결과 저장] [PDF로 저장] [전체 문서 보기] [정밀 분석 요청서 초안](옵션 D일 때).

**시안과 다른 점:** 두 열 비교(원안 열 + 보완안 열) 대신 **보완안 한 줄 목록 + 변경 전후 표**로 만들었다. 두 열은 좁은 화면에서 어차피 위아래로 접히고, 같은 내용을 두 번 보여주게 된다. 원안 문장은 변경 전후 표의 "원안" 칸에서 확인한다.

### `document.html`

생성된 Markdown 전체를 읽기 전용으로 표시. [결과 저장] 버튼 동일 제공.

### `request.html`

시안 "별첨 요청서" 기준. 요청 목적, 분석 대상(미정이면 추가 확정 필요), 기간·단위, 필요 지표, 확인 필요(점포 식별·자료 제공·계약·비용). 하단 고정 문구 "※ 초안이며 계약·자료 제공이 확정된 것이 아닙니다."
