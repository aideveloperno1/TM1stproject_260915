# web/templates/ — Jinja2 HTML 템플릿

## 역할

서버가 렌더링하는 화면. 계산·판단 없이 라우트가 넘긴 값을 표시만 한다.
Jinja2 자동 이스케이프가 켜져 있으므로 사용자 입력에 `|safe`를 쓰지 않는다.

## 기준

- 디자인: `기획서 보완 서비스 랜딩페이지/정책맵 워크스페이스.dc.html` 시안 (흰 카드, 파란 강조 #2563EB, Pretendard, 단계 표시줄, 근거 칩)
- checks.md 시안 차이 결정: 5단계, 규칙 표시는 최종기획 기준. [PDF로 저장]은 9/16에 추가(브라우저 인쇄 방식)

## 하위 폴더

| 폴더 | 내용 |
|---|---|
| `steps/` | 단계별 전체 화면 |
| `partials/` | 여러 화면에서 반복되는 조각 |

## 만들 파일

| 파일 | 상태 | 내용 |
|---|---|---|
| `base.html` | 있음 | 공통 틀: head(Pretendard·CSS), 상단바(서비스명·"시연용 합성 수치"·[처음으로]), 단계 표시줄, `content`·`scripts` 블록 |
| `error.html` | 있음 | 근거 파일 로드 실패 안내 (오류 목록, 다음 행동). 2·3단계에서 HTTP 503으로 표시 |

## `base.html` (있음)

- 상단 칩에 불러온 근거 파일의 종류·버전 표시 (`evidence.badge`), 오류면 `tag-error`
- 단계 표시줄: 원안을 보관하기 전에는 1단계만 열림
- 하단 고지: 합성/실제 표시 + "BC카드 공식 서비스가 아닙니다 · 공모전 제안용"
- 모든 화면은 `templating.render()`로 그린다. 문맥에 `evidence`가 없으면 페이지 전체가 템플릿 오류가 난다

## 원칙

- 수치 표시는 `web/formatters.py` 필터만 사용 (`{{ value | pct }}`). 템플릿 안에서 반올림·계산 금지
- None 값은 필터가 "자료 없음"/"계산 불가"로 바꾼다. `or 0` 같은 기본값 금지
- 색상: 방향 차이는 회색·파랑 중립색, 추가 확정 필요만 노랑(#A8761A). 빨간 경고 금지 (워크플로우 8-3)
- 모든 화면에서 "문제없음"과 "검토하지 않음"을 구분해 표시
- JS가 쓸 데이터는 `<script type="application/json">{{ data | tojson }}</script>`로 넘긴다
